Lattice — the editor shell

A real GrapesJS canvas showing a projection: the page you see is compiled by the same binary lattice build runs, ported to WebAssembly and inlined into this page. Every control emits an op against the IR — there is no CSS box anywhere in this UI.

  • click an element — the inspector offers tokens, never values
  • drag a card by the ✥ handle — the drop becomes a column and a span
  • ⌘Z undoes an op batch, from the engine's history
  • watch the meter and the debt counter as you edit
