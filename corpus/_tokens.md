# Corpus token conventions

Every corpus site carries its own token set (sites are self-contained so the determinism job can
compile any one of them in isolation). The names below are shared by convention so a reader can
compare two sites without re-learning the vocabulary:

`color.bg` `color.surface` `color.fg` `color.muted` `color.accent` `color.on-accent`
`space.1`…`space.8` (4px scale) · `type.body` `type.lead` `type.h1` `type.h2` `type.h3` `type.small`
`radius.sm` `radius.md` `radius.lg`

Contrast pairings are chosen to pass the prove-pass at 4.5:1 for body text and 3:1 for large text.
